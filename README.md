# CodeAlpha_HandwrittenCharacterRecognition

Handwritten Character Recognition using CNN and PyTorch for CodeAlpha Internship

## Task 3: Handwritten Character Recognition

### Objective
Identify handwritten digits (0-9) using a Convolutional Neural Network.

### Dataset
MNIST — 60,000 training images and 10,000 test images

### Model
Convolutional Neural Network (CNN) built with PyTorch

### Steps
- Loaded and preprocessed MNIST dataset
- Built CNN model with 2 convolutional blocks
- Trained model for 10 epochs
- Evaluated using accuracy and classification report
- Visualized results with confusion matrix and sample predictions

### Best Result
Test Accuracy: 99.43%

### Libraries Used
- PyTorch
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
